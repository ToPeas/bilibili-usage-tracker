Cloudflare D1 配置

需要你的 Cloudflare Account ID、D1 Database ID 以及一个 D1:Edit 权限的 API Token。 查看官方文档 →

数据说明

  • 本地按「日 + 小时」两级桶累积，service worker 每天自动把脏数据上传一次；也可以在 popup 中手动「立即上传」。
  • D1 中表 usage_daily 存每天每设备总时长；usage_hours 存每天 24 小时分布；usage_items 存每天各域名分布。
  • 插件最多保留本地 200 天的明细，上传范围最近 30 天；如需展示更多历史，由查询时直接读取 D1。
